## 题目描述

读入一行，空格分词，`#` 结束；统计各不同单词次数，输出 `词-次数`。
（实现冗长有 bug，题意经典词频。）

## 输入格式

一行，以 # 结束。

## 输出格式

若干 词-次数。

## 样例

输入：to be or not to be#
输出（意图）：to-2 be-2 or-1 not-1

## 思路要点

切词后首次出现时向后计数。
