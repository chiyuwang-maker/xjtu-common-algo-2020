## 题目描述

n 条记录：ID、签到、签退（`HH:MM:SS`）。输出最早签到 ID 与最晚签退 ID。

## 输入格式

n；随后 n 行 ID in out。

## 输出格式

两个 ID。

## 样例

输入：
3
CS001 08:00:00 17:30:00
CS002 07:55:00 18:00:00
CS003 08:10:00 17:45:00
输出：
CS002 CS002
