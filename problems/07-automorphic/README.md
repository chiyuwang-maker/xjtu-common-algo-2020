## 题目描述

自守数：m² 的十进制末尾恰好等于 m。给定闭区间 [x,y]，输出其中全部自守数。
判定：设 m 有 n 位，t=10ⁿ，则 (m²−m) % t == 0。

## 输入格式

两个整数 x y。

## 输出格式

自守数升序，空格分隔。

## 样例

输入：1 100
输出（构造）：1 5 6 25 76

## 思路要点

用 10^位数取模识别末尾。
