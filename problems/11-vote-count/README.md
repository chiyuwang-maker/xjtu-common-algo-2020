## 题目描述

选票为 1/2/3，其它为无效；以 -1 结束。输出三人得票与无效票数。
（`0<c<4` 在 C 中非区间判断；Project13 为字符串草稿。）

## 输入格式

若干整数，-1 结束。

## 输出格式

四个整数：a1 a2 a3 invalid。

## 样例

输入：1 2 1 3 5 2 -1
输出（意图）：2 2 1 1

哨兵结束+分箱。
