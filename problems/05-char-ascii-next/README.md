## 题目描述

连续读入 4 个字符；对每个字符输出：自身、ASCII 码、码点+1 的后继字符。
（Project4 为同题更乱草稿，作 draft 附上。）

## 输入格式

四个字符。

## 输出格式

四行：`字符 ASCII 后继`。

## 样例

输入：AbZ!
输出（构造）：
A 65 B
b 98 c
Z 90 [
! 33 "

## 思路要点

体会 char/int 互通。
