## 题目描述

某销售员按当月利润 y（元）计算提成，分段规则如下（与源码分支一致；其中 10 万档公式疑似笔误，按代码保留）：

- y < 100000：提成 = y × 0.1
- 100000 ≤ y < 200000：`(y-10000)*0.08 + 10000`（源码如此）
- 200000 ≤ y < 400000：`(y-200000)*0.08 + 10000`
- 400000 ≤ y < 600000：`(y-400000)*0.03 + 28000`
- 600000 ≤ y < 1000000：`(y-600000)*0.02 + 34000`
- y ≥ 1000000：`(y-1000000)*0.01 + 42000`

输出提成（源码用 `%d` 打印，浮点结果截断为整数）。

## 输入格式

一个整数 y。

## 输出格式

一个整数：提成金额。

## 样例

输入：
50000
输出（据代码构造）：
5000

## 思路要点

多分支分段累进；注意边界落档。
