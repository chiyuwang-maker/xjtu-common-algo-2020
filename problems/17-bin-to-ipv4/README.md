# 17 二进制串转点分IP

> **说明**：题面由源码反推，非原始试卷原文。

- **考点**：进制/位权

## 题目描述

读入 0/1 串（不足 32 位高位补 0），转 `a.b.c.d`；含非法字符则提示非正确 IP。

## 输入格式

一行 0/1 串。

## 输出格式

点分十进制或错误提示。

## 样例

输入：11000000101010000000000100000001
输出（构造）：192.168.1.1

## 思路要点

每 8 位一组累加。
