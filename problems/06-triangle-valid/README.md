## 题目描述

给定三边长（浮点），判断能否构成三角形：任意两边之和大于第三边。能则 `YES`，否则 `ERROR DATA`。
（源码误用按位 `&`，题面按逻辑与。）

## 输入格式

三个浮点数。

## 输出格式

`YES` 或 `ERROR DATA`。

## 样例

输入：3 4 5
输出：YES

## 思路要点

三角形不等式。
