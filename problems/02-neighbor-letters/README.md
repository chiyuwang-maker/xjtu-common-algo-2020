# 02 大写字母的左邻右舍

> **说明**：题面由源码反推，非原始试卷原文。
> 作者为大一下用 Visual Studio「一项目一题」手作练习。

- **原项目**：`Project2`
- **源文件**：`源.c`
- **考点**：字符/环形

## 题目描述

读入一个大写字母，输出其在字母表中的「前一个、自身、后一个」。字母表首尾环形：A 的前驱为 Z，Z 的后继为 A。

## 输入格式

一个大写字母。

## 输出格式

三个连续字符，如 `ABC`。

## 样例

输入：B  
输出：ABC  

输入：A  
输出：ZAB  

输入：Z  
输出：YZA  

## 原练习思路（已留在源码注释）

当时源码 A/Z 分支误用 `=` 赋值而非 `==` 比较；中间字母 ±1。注释保留笔误说明；主路径已改为 `==` + `else if`。
