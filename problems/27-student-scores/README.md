# 27 学生成绩录入

> **说明**：题面由源码反推，非原始试卷原文。
> 作者为大三下（约2023）用 Visual Studio「一项目一题」手作练习。

- **原项目**：`Project32`
- **源文件**：`源.c`
- **考点**：结构体数组

## 题目描述

用结构体保存学生学号、姓名、三门成绩。交互录入 10 人后，按「学号 姓名 平均分」输出每人结果（平均分保留两位小数）。

## 输入格式

对每位同学依次读入：`学号` `姓名` `成绩1` `成绩2` `成绩3`（共 10 人）。提示语为中文交互。

## 输出格式

先打印表头 `学号 姓名 平均分`，再 10 行每人数据。

## 样例（示意；人数 mixed，实际为 10 人）

录入片段：
```
1 Alice 90 80 70
```
对应输出行意图：
```
1 Alice 80.00
```
