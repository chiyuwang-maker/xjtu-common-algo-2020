## 题目描述

P0=1，P1=x；n>1 时 Pn=((2n-1)x Pn-1-(n-1)Pn-2)/n。读 n 与 x，输出 Pn(x)。

## 输入格式

整数 n 与浮点 x。

## 输出格式

一个浮点数。

## 样例

输入：2 0.5
输出：-0.125
