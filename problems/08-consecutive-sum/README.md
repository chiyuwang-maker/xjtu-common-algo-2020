# 08 连续正整数之和分解

- **考点**：数论/连续和

## 题目描述

给定正整数 a，找出所有「至少两个连续正整数之和等于 a」的写法，按 `a=…+…` 打印。
巧思：若连续 i 项之和为 a，则 2a 可被 i 整除；由 i 奇偶推出首末项。

## 输入格式

正整数 a。

## 输出格式

若干行分解式。

## 样例

输入：9
输出（意图）：
9=2+3+4
9=4+5

## 思路要点

由段长与 2a 整除关系构造区间。
