## 题目描述

读入一行，删除前缀与后缀连续 `*`，保留中间（含中间的 `*`）。

## 输入格式

一行字符串。

## 输出格式

剥边后的子串。

## 样例

输入：***abc*de**
输出：abc*de

## 思路要点

左右找首尾非星。
