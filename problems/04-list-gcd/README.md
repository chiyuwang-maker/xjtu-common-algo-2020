## 题目描述

读入若干正整数，以 0 结束（0 不计入）。求这些数的最大公约数，并回显原数列。
（源码有拼写/控制流 bug；题面按意图。Project14 的 `源.cp` 为同题草稿。）

## 输入格式

若干正整数，以 0 结束。

## 输出格式

第一行 GCD；第二行原数列。

## 样例

输入：12 18 24 0
输出（意图）：
6
12 18 24
