## 题目描述

实现 `ispalindrome(n)`；主程序读上界 n，输出 [1000,n] 内全部回文数。

## 输入格式

整数 n（≥1000）。

## 输出格式

回文数空格分隔。

## 样例

输入：1010
输出（构造）：1001
