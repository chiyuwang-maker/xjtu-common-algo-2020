## 题目描述

a 名新兵编号 1…a。反复：去掉当前位置为偶数者；若仍>3，再去掉位置为 3 倍数者；直到剩余≤3。a=3 特判输出 1 2 3。

## 输入格式

整数 a（代码限制约 (3,6000)）。

## 输出格式

剩余编号空格分隔。

## 样例

输入：3
输出：1 2 3

## 思路要点

两轮不同淘汰规则交替，构思巧妙。
