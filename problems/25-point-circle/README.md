# 25 点与圆位置

- **考点**：几何 / 点到圆心距离

## 题目描述

读入点坐标 `(x,y)`，判断该点相对圆心 `(2,2)`、半径 `1` 的位置：距离 \(\le 1\) 为圆内（含边界），否则为圆外。

## 输入格式

一行：`(x,y)`（含括号与逗号，如 `(3,2)`）。

## 输出格式

- 圆内（含边界）：`IN`
- 圆外：`OUT`

## 样例

输入：
```
(3,2)
```
输出：
```
IN
```
（到 (2,2) 距离为 1，在圆周上，属圆内。）

输入：
```
(2,2)
```
输出：
```
IN
```

输入：
```
(5,2)
```
输出：
```
OUT
```
