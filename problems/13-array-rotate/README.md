## 题目描述

读入数组长度 \(a\)、移位量 \(l\)，以及 \(a\) 个整数。将序列**循环右移** \(l \bmod a\) 位后输出。

## 约束（据作者回忆）

- **不允许为结果另开新数组**；须在原数组上完成移位（可用少量标量临时变量）。

## 输入格式

第一行：`a` `l`  
第二行：`a` 个整数

## 输出格式

移位后的序列（空格分隔）。

## 样例

输入：
```
6 2
1 2 3 4 5 6
```
输出（右移 2 位）：
```
5 6 1 2 3 4
```

## 原练习思路（已留在源码注释）

当时源码按 \(a\) 与移位步长的整除关系分支：逐步挪格，或沿环做置换；环上置换时用整型临时量保存被覆盖的值。源码注释中保留了该思路与已知笔误说明，**主路径已不再执行**。

## 当前解法：三次逆置 / 截点倒位

**O(n) 时间、O(1) 额外空间**（逆置交换只需 **一个整型中间变量**）：

设 \(b = l \bmod a\)（右移位数）。若 \(b \ne 0\)：

1. 逆置 \([0,\ a-b-1]\)
2. 逆置 \([a-b,\ a-1]\)
3. 逆置 \([0,\ a-1]\)

口语里有时会把这种又快又省空间的原地法说成「快排方法」；这里指的是高效移位套路，**不是** quicksort 快速排序。

参考关键词：数组循环左移/右移、三次逆置、手摇算法、PAT 1008。
